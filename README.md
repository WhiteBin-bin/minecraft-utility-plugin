# Minecraft Plugin

마인크래프트 편의 기능 플러그인입니다.

## 기능

- 개인 창고 명령어
- 개인 창고 확장
- 개인 창고 축소
- 개인 창고 정렬
- 개인 창고 초기화
- 개인 창고 공유
- 개인 창고 로그
- 창고 로그 및 공유 목록 GUI
- 명령어 자동완성
- 플레이어 잔액 저장
- 플레이어 잔액 조회 명령어
- OP 전용 플레이어 잔액 관리 명령어
- 접속 시 잔액 사이드바 표시
- OP의 다른 유저 창고 접근
- 플레이어 UUID 기준 창고 데이터 저장

## 경제

- 플레이어 UUID 기준으로 잔액을 저장합니다.
- 저장된 잔액이 없으면 기본 잔액은 `0`입니다.
- 잔액 데이터는 `plugins/minecraft_plugin/economy/<uuid>.yml`에 저장됩니다.
- 플레이어가 서버에 접속하면 오른쪽 사이드바에 현재 잔액이 표시됩니다.
- `/money`와 `/돈` 명령어로 잔액을 조회할 수 있습니다.
- OP는 `/money`와 `/돈` 명령어로 플레이어 잔액을 지급, 차감, 설정할 수 있습니다.

## 명령어

| 명령어 | 한글 명령어 | 설명                        |
| --- | --- |---------------------------|
| `/storage` | `/창고` | 자신의 개인 창고를 엽니다.           |
| `/storage <player>` | `/창고 <player>` | 공유받은 유저 또는 OP가 다른 유저의 창고를 엽니다. |
| `/storage expand` | `/창고 확장` | 자신의 개인 창고를 9칸 확장합니다.(OP만 사용가능) |
| `/storage expand <player>` | `/창고 확장 <player>` | 다른 유저의 개인 창고를 9칸 확장합니다.(OP만 사용가능) |
| `/storage shrink` | `/창고 축소` | 자신의 개인 창고를 9칸 축소합니다.(OP만 사용가능) |
| `/storage shrink <player>` | `/창고 축소 <player>` | 다른 유저의 개인 창고를 9칸 축소합니다.(OP만 사용가능) |
| `/storage sort` | `/창고 정렬` | 자신의 개인 창고 아이템을 정렬합니다. |
| `/storage sort <player>` | `/창고 정렬 <player>` | 다른 유저의 개인 창고 아이템을 정렬합니다.(OP만 사용가능) |
| `/storage clear` | `/창고 초기화` | 자신의 개인 창고 아이템을 초기화합니다. |
| `/storage clear <player>` | `/창고 초기화 <player>` | 다른 유저의 개인 창고 아이템을 초기화합니다.(OP만 사용가능) |
| `/storage share <player>` | `/창고 공유 <player>` | 자신의 개인 창고를 다른 유저에게 공유합니다. |
| `/storage unshare <player>` | `/창고 공유해제 <player>` | 다른 유저에게 공유한 개인 창고를 해제합니다. |
| `/storage shares` | `/창고 공유목록` | 내가 공유 중인 유저 목록을 GUI로 확인합니다. |
| `/storage shared` | `/창고 공유받은목록` | 내가 공유받은 창고 목록을 GUI로 확인합니다. |
| `/storage logs <player>` | `/창고 로그 <player>` | 특정 유저의 개인 창고 로그를 GUI로 확인합니다.(OP만 사용가능) |
| `/money` | `/돈` | 자신의 잔액을 확인합니다. |
| `/money <player>` | `/돈 <player>` | 특정 유저의 잔액을 확인합니다.(OP만 사용가능) |
| `/money give <player> <amount>` | `/돈 지급 <player> <amount>` | 특정 유저에게 돈을 지급합니다.(OP만 사용가능) |
| `/money take <player> <amount>` | `/돈 차감 <player> <amount>` | 특정 유저의 돈을 차감합니다.(OP만 사용가능) |
| `/money set <player> <amount>` | `/돈 설정 <player> <amount>` | 특정 유저의 돈을 설정합니다.(OP만 사용가능) |

## GUI

- `/storage logs <player>`와 `/창고 로그 <player>`는 창고 로그 GUI를 엽니다.
- `/storage shares`와 `/창고 공유목록`은 내가 공유 중인 유저 목록 GUI를 엽니다.
- `/storage shared`와 `/창고 공유받은목록`은 내가 공유받은 창고 목록 GUI를 엽니다.
- GUI 안의 아이템은 이동하거나 가져갈 수 없습니다.
- 목록이 비어 있어도 빈 상태 안내 아이템이 표시됩니다.
- 목록이 45개를 초과하면 이전/다음 페이지 버튼으로 이동할 수 있습니다.
- 이전 페이지 버튼은 GUI 하단 왼쪽 끝, 다음 페이지 버튼은 GUI 하단 오른쪽 끝에 표시됩니다.
- 필터 버튼은 GUI 하단 가운데에 표시됩니다.
- 필터 버튼을 누르면 필터 선택 GUI가 열리고, 원하는 필터를 클릭해 적용할 수 있습니다.
- 창고 로그 GUI는 전체 로그와 작업 타입별 로그 필터를 지원합니다.
- 공유 목록과 공유받은 목록 GUI는 전체, 접속 중, 미접속 필터를 지원합니다.

## 자동완성

- `/storage` 명령어는 영어 하위 명령어를 자동완성합니다.
- `/창고` 명령어는 한글 하위 명령어를 자동완성합니다.
- 첫 번째 인자 위치에서는 하위 명령어와 현재 서버에 접속 중인 플레이어 이름을 자동완성합니다.
- 플레이어 인자가 필요한 명령어에서는 현재 서버에 접속 중인 플레이어 이름을 자동완성합니다.
- 일반 유저에게는 OP 전용 명령어가 자동완성 후보로 표시되지 않습니다.

| 입력 | 자동완성 후보 |
| --- | --- |
| `/storage <Tab>` | `expand`, `shrink`, `sort`, `clear`, `share`, `unshare`, `shares`, `shared`, `logs`, 현재 서버에 접속 중인 플레이어 이름 |
| `/창고 <Tab>` | `확장`, `축소`, `정렬`, `초기화`, `공유`, `공유해제`, `공유목록`, `공유받은목록`, `로그`, 현재 서버에 접속 중인 플레이어 이름 |
| `/storage logs <Tab>` | 현재 서버에 접속 중인 플레이어 이름 |
| `/창고 로그 <Tab>` | 현재 서버에 접속 중인 플레이어 이름 |
| `/money <Tab>` | `give`, `take`, `set`, 현재 서버에 접속 중인 플레이어 이름 |
| `/돈 <Tab>` | `지급`, `차감`, `설정`, 현재 서버에 접속 중인 플레이어 이름 |
| `/money give <Tab>` | 현재 서버에 접속 중인 플레이어 이름 |
| `/돈 지급 <Tab>` | 현재 서버에 접속 중인 플레이어 이름 |

## 요구사항

- Java 21
- Paper 1.21.11

## 빌드

```bash
./gradlew build
```

플러그인 jar 파일은 아래 경로에 생성됩니다.

```text
build/libs/
```

## 개발

로컬 Paper 서버를 실행하려면 아래 명령어를 사용합니다.

```bash
./gradlew runServer
```
